# Dual-comb polarization-multiplexing ring-cavity fiber laser for ranging applications

Project page for the article

> A. Rodriguez Cuevas, D. Stoliarov, H. Kbashi and S. Sergeyev, "Dual-comb polarization-multiplexing ring-cavity fiber laser for ranging applications", *Optics Express* 33(8), 18161–18168 (2025). [doi:10.1364/OE.555772](https://doi.org/10.1364/OE.555772) (open access, CC BY 4.0)

## Contents

- `index.html`, `assets/`: the page, served with GitHub Pages. No build step and no external dependencies.
- The animations (local oscillator sampling the echoes, ring cavity) and the scale-factor calculator are illustrations built on the published values.
